## 4. One check, one SQL statement, two sources

`ward_actually_understaffed` as sent to Zetaris in run `run_a5cc78cadb`. The `demand` and `roster` tables are in the
CSV file source and `leave` is in Postgres, all joined in one read-only statement:

```sql
SELECT d.ward AS ward, d.shift_date AS shift_date, d.shift_type AS shift_type, d.required_nurses AS required_nurses, d.required_skill AS required_skill, COUNT(r.staff_id) AS available_rostered FROM PREFLIGHT_FILES.demand d LEFT JOIN ( SELECT ro.staff_id AS staff_id, ro.ward AS ward, ro.shift_date AS shift_date, ro.shift_type AS shift_type FROM PREFLIGHT_FILES.roster ro LEFT JOIN ( SELECT lv.staff_id AS staff_id FROM preflight_pg.leave lv WHERE lv.status = 'approved' AND lv.start_date <= DATE '2026-10-27' AND lv.end_date >= DATE '2026-10-27' ) away ON away.staff_id = ro.staff_id WHERE ro.ward = '4B' AND ro.shift_date = DATE '2026-10-27' AND ro.shift_type = 'night' AND away.staff_id IS NULL ) r ON r.ward = d.ward AND r.shift_date = d.shift_date AND r.shift_type = d.shift_type WHERE d.ward = '4B' AND d.shift_date = DATE '2026-10-27' AND d.shift_type = 'night' GROUP BY d.ward, d.shift_date, d.shift_type, d.required_nurses, d.required_skill
```

`has_required_skill` joins the file source with the REST skills service the same way:

```sql
SELECT d.required_skill AS required_skill, sk.skill AS held_skill FROM PREFLIGHT_FILES.demand d LEFT JOIN PREFLIGHT_API.staff_skills sk ON sk.skill = d.required_skill AND sk.staff_id = 'S001' WHERE d.ward = '4B' AND d.shift_date = DATE '2026-10-27' AND d.shift_type = 'night'
```
